# Front · Next.js

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # build de producción
npm run lint && npx tsc --noEmit
```

Variables: ver `.env.example`. La documentación está en [`../docs`](../docs) (empieza por [ARCHITECTURE.md](../docs/ARCHITECTURE.md)).

> Next.js 16 cambia bastantes APIs respecto a versiones anteriores: la referencia fiable es la documentación incluida en `node_modules/next/dist/docs/`.
