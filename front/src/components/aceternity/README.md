# Aceternity-style components

Adapted from [Aceternity UI](https://ui.aceternity.com) (copy-paste library, MIT-style usage).
Changes vs. the originals:

- Use `motion/react` (Framer Motion's current package name).
- Respect `useMotionPreference()` → static rendering when motion is reduced.
- Recoloured with the project tokens (violet / cyan / magenta).
- No extra runtime deps (e.g. Sparkles uses a tiny canvas instead of tsparticles).
